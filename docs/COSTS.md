# Модели и размещение: оценка расходов

Проверено по официальным тарифам **29 октября 2026 года**. Ни платный API, ни оплачиваемый сервер сейчас не подключены. Цены ниже в USD, без налогов, конвертации и возможных комиссий.

## Почему расписание могло разбираться неправильно

Причин несколько: OCR теряет расположение строк и столбцов; небольшая текстовая Qwen3 4B не видит саму фотографию; правила ошибочно выбирали один встреченный предмет вместо типа всей таблицы. Смена модели может улучшить понимание, но не исправляет неправильную проверку ответа автоматически.

В локальной версии добавлено распознавание структуры расписания: предметы вместе с номерами уроков/кабинетов, либо времена начала/окончания и перемены. Одной фразы «очно-заочное обучение» недостаточно: это также бывает список вступительных предметов. Устранены выбор случайного предмета для всей таблицы и путаница сочинения с лекцией из-за слова внутри текста.

Для следующего шага нужна **мультимодальная модель**, которой можно передать сам снимок или изображения первых четырёх страниц. Она сможет учитывать таблицу и расположение элементов, а OCR останется вспомогательным источником. Адаптер Gemini уже умеет передавать такие изображения. Без ключа приложение продолжает использовать локальный текстовый режим.

## Что такое вход, выход и токены

- **Вход** — всё, что программа отправляет модели: текст документа или OCR, пояснение, инструкция анализа и подходящие прошлые примеры. Для модели с изображениями сюда входит и само изображение.
- **Выход** — сгенерированный моделью результат: тип материала, подборка, описание, основания. У некоторых моделей оплачиваются также внутренние рассуждения.
- **Токен** — небольшой фрагмент текста: часть слова, слово, число или знак. Это не ровно одно слово и не одно сообщение Telegram. Разные модели разбивают текст по-разному.
- **Цена за миллион токенов** — единица тарифа. Не требуется отправить миллион, чтобы началось списание; небольшой запрос стоит соответствующую долю этой цены.

Пример для Sol: если запрос занял 4000 входных токенов, это $0.008. Если оплачиваемый ответ занял 500 выходных, это $0.005. Вместе **$0.013 за один такой разбор**, или **$1.30 за 100**, или **$13 за 1000**. Объём взят для иллюстрации; это не измеренный размер каждого личного файла.

**1000 разборов** означает 1000 обращений к модели. Например, это может быть 1000 файлов по одному разу либо 500 файлов, каждый из которых проанализирован дважды. Добавление пояснения может запустить дополнительные разборы старых материалов, и они тоже считаются запросами.

## Какую модель пробовать

Для выбранного подключения используем **Gemini 3.8 Flash**: модель принимает изображения и подходит по цене для частого разбора сохранений. Адаптер готов, настоящий ключ добавляется в локальных настройках. **GPT-6.1 Sol** остаётся вариантом для будущего сравнения; бюджетный вариант — **GPT-6 Luna**. Это рекомендация для испытания, не результат уже выполненного платного сравнения. Выбирать окончательно следует после проверки одинаковых фотографий расписаний, сочинений, PDF и неясных записей, включая ложные переносы.

| Модель | Вход, за 1 млн токенов | Выход, за 1 млн токенов | 1000 текстовых разборов по условию ниже |
|---|---:|---:|---:|
| [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) | $2.00 | $10.00 | $13.00 |
| [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.8-flash) | $0.75 | $3.75 | $4.88 |
| [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) | $0.10 | $0.50 | $0.65 |

Условие расчёта: **4000 входных + 500 оплачиваемых выходных токенов на материал**, по одному запросу, обычный тариф, без кеша, поиска в интернете и изображений. Формула: `1000 × (4000 × цена_входа + 500 × цена_выхода) / 1 000 000`. Это иллюстрация расходов, не обещание цены для произвольного PDF. Длинные документы, изображения, дополнительные рассуждения, повторные анализы и пересмотр старого архива увеличивают счёт.

Указанные цены Gemini 3.8 Flash действуют до **31 декабря 2026 года**; с 1 января 2027 года официально объявлены $1.50/$7.50. У Gemini есть бесплатный тариф с ограничениями, но на нём материалы могут использоваться для улучшения продуктов; на обычном платном тарифе — нет. Для личного архива бесплатный тариф не следует выбирать только ради экономии без учёта этих условий. [Источник Google](https://ai.google.dev/gemini-api/docs/pricing).

API оплачивается за использование и не требует аренды собственного GPU. Доступность конкретного провайдера, модели и способа оплаты нужно проверить для аккаунта до подключения. Сейчас ключи внешних провайдеров не добавлены.

## Для чего отдельное облако

**API модели** — удалённый вычислитель: получает разрешённый материал, возвращает результат.

**Хостинг бота** — постоянно работающий компьютер: принимает Telegram-сообщения, обслуживает Mini App, хранит базу и файлы, выполняет задачи, пока личный Mac выключен. Это разные расходы.

Можно оставить сервер на Mac и платить только за API модели. Облако нужно, когда требуется круглосуточная работа, постоянный HTTPS-адрес и независимость от домашнего компьютера. Перенос сам по себе не делает модель умнее.

### Пример размещения на Render

Официальные цены [Render](https://render.com/pricing):

- Небольшой сервер: **$7/месяц**, 512 МБ RAM.
- Постоянный диск: **$0.25 за ГБ в месяц**; 10 ГБ — $2.50.
- Условный минимум: **$9.50/месяц** за сервер + 10 ГБ диска.
- Сервер с 2 ГБ RAM: **$25/месяц**, с тем же диском — **$27.50/месяц**.

Модель API оплачивается отдельно. Пример: маленький сервер + диск + 1000 условных текстовых разборов Sol = **$22.50/месяц** до дополнительных расходов. Это конфигурационная оценка, а не гарантированная квота на все файлы и задачи.

512 МБ достаточно обсуждать для облегчённого сервиса, который обращается к внешним моделям; локальные Qwen, OCR macOS и whisper нельзя просто перенести туда без адаптации. Текущий проект использует Apple Vision/PDFKit. Перед развёртыванием на Linux потребуются замена OCR/vision, настройка хранения и проверка памяти. Тариф с 2 ГБ даёт больше запаса, но также не превращает сервер в полноценную машину для больших локальных моделей.

Файлы, трафик сверх включённого, отдельные резервные копии и увеличение ресурсов могут добавить расходы. Бесплатный тестовый хостинг не следует считать гарантией постоянной работы и сохранности диска. На текущем этапе для нескольких тестировщиков можно сохранить Mac и сначала проверить качество платной модели, не арендуя сервер.

## Что подготовлено и что не подключено

Генерация результата отделена в `PersonalAnalyzer`, формат `Analysis` и память пользователя уже существуют. Реализован адаптер Gemini 3.8 Flash: передача подготовленных изображений, структурированный результат, подсчёт входных токенов и резерв расходов. Подмена одной строки `OLLAMA_URL` не разрешена; ключ добавляется на Mac в настройках. Собственный сервер остаётся локальным. Парольный раздел не должен передаваться ни одному провайдеру. Перед подключением полезно установить ограничение расходов в аккаунте и измерять реальное использование.
