# Изbrainое для Android и Mac

Первая версия отдельного приложения. Главный экран — **чат с собой**: только сохранённые заметки, ссылки и оригиналы. Поиск, подборки, пояснения и пароли открываются отдельно. Собственный постоянно работающий сервер приложению не нужен.

## Android 0.2.5

- В чате и поиске — статичный фон «За краем», чёрная дыра с заметностью 23%. Фон рисуется отдельно от списка и не перехватывает касания; клавиатура не меняет его масштаб.
- Встряхивание Android-телефона открывает подборки; из списка подборок или открытой папки возвращает в чат с коротким тактильным откликом. На основных экранах поиска и паролей встряхивание также открывает подборки. Диалоги, настройки и отдельные карточки материалов не прерываются.
- Для жеста нужны два противоположных движения, затем действует пауза 1,5 секунды. Датчик отключается при сворачивании. Фон и жест работают локально, без запросов Gemini.

Готовый подписанный APK собирается в `build/app/outputs/flutter-apk/app-release.apk`. Поддерживаются Android 8+ и ARM64. Установка — открытием APK на телефоне с разрешением установки для выбранного источника. Google Play для личного тестирования не требуется.

- Входящие материалы: системное «Поделиться», несколько вложений или выбор файлов, текстовый ввод в чате.
- Оригиналы копируются в собственное хранилище; удаление исходного вложения в Telegram не удаляет копию приложения.
- Один материал имеет одну основную подборку. Дополнительные смыслы остаются в ключевых словах, описании и поиске. Ручная подборка имеет приоритет.
- Поиск запускается кнопкой или фразой «найди …» в чате. Запросы не добавляются в ленту.
- Доступ к подходящему паролю по названию сервиса требует разблокировки отдельного хранилища.
- Удаление переносит запись в корзину; пояснение ровно «удалить» делает то же самое.
- Пояснение может сопровождаться ручным выбором темы. Подборке можно задать форматы, например `mp3, flac`; правило применяется и к прежним записям без ручной темы и личного контекста.

### Настройка Gemini по QR

1. Установить Android 0.2.4 или новее.
2. На Mac открыть «Подключить Gemini.command» либо запустить `.venv/bin/python scripts/prepare_android_transfer.py --open`. Нужны `qrcode==8.2` и зависимости старого приложения.
3. На телефоне открыть «Настройки → Настроить по QR», отсканировать личный код и подтвердить подключение.

QR содержит только ключ провайдера Gemini, модель и месячный лимит расходов. В нём нет файлов, заметок, папок, правил, паролей, ключа старого архива или адреса его скачивания. Сервер переноса не запускается; общая Wi-Fi сеть не требуется. Генератор удаляет старые копии переноса в `data/android-transfer`, сохраняя оригинальный архив Mac. Прежний ярлык «Перенести с Mac.command» также открывает новый код настроек.

Сканирование меняет только настройки Gemini и сохраняет существующие материалы на телефоне. Для чистого старта сначала нажать «Очистить абсолютно всё» на телефоне, затем сканировать новый код. Полная очистка телефона удаляет также его настройки и API-ключ. Резервные копии архива восстанавливаются отдельно, через соответствующую команду приложения.

Код содержит API-ключ: его нельзя публиковать или передавать посторонним. Ключ не входит в APK или Git. Старый Telegram-бот остаётся отдельным приложением и не синхронизируется с Android автоматически.

## Анализ

Gemini вызывается напрямую через Provod с пользовательским ключом. Фото передаётся как изображение JPEG с ограничением длинной стороны 1536 px; OCR Mac не нужен. Для PDF визуализируются первые четыре страницы, оригинал остаётся целиком. На Android используется встроенный рендерер PDF. Нативное декодирование дополняет поддержку изображений, например HEIC на совместимых версиях Android.

Текст, код и конфигурации читаются ограниченным фрагментом. Из DOCX/XLSX/PPTX/ODF/EPUB извлекаются текстовые XML-части. ZIP разбирается ограниченным списком файлов, содержимое не выполняется; размер распаковки ограничен. Неподдерживаемые двоичные форматы сохраняются целиком без заявления, что они прочитаны.

Без дополнительного контекста музыка, видео и ZIP сортируются по формату без платного вызова модели. Расшифровка аудио, запись голоса и покадровый анализ видео в этой версии не реализованы. Для остальных материалов выполняются максимум два одновременных разбора. Публичная справка по неизвестному общему термину может вызвать ограниченный дополнительный проход. Сам файл в поисковый сервис не загружается.

Короткий запрос поиска и сжатые описания кандидатов обрабатываются Gemini. В первой версии выборка ограничена 200 кандидатами: сначала совпадения обычного поиска, затем новые материалы. На больших архивах семантический поиск старых записей без совпадающих слов пока может быть неполным.

Оценка расходов хранится на устройстве, резерв записывается до запроса. Расход неопределившегося запроса остаётся в резерве. Лимит устройства не заменяет ограничение в кабинете Provod и не является общим банковским лимитом для двух устройств. Тарифы оценки перенесены из существующей интеграции; фактическое списание определяет провайдер.

Без сети можно сохранять и открывать локальные материалы. Обработка очереди и синхронизация работают, пока процесс приложения активен; отложенные задания возобновляются при открытии приложения. Постоянная фоновая работа при принудительной остановке Android не обещается.

## Хранение и синхронизация

- Каждый архив имеет случайный ключ 256 бит. Ключ и API-токены находятся в защищённом хранилище платформы.
- Метаданные — неизменяемые AES-GCM события. Каждый файл — AES-GCM фрагменты по 1 МиБ. Назначение и идентификатор связаны через AAD.
- Оригинал проверяется SHA-256 после расшифровки каждого полного приёма.
- Синхронизация реализована через REST API Яндекс Диска с правом папки приложения. Требуется отдельное подключение аккаунта/токена; автоматически аккаунт Яндекса не создаётся.
- После подтверждения от всех зарегистрированных устройств (минимум двух) облачная папка оригинала удаляется. Локальные оригиналы остаются.
- Пока второе устройство выключено, зашифрованные файлы ожидают в облаке. При переполнении локальный оригинал сохраняется.
- Новое устройство публикует запрос недостающего оригинала; уже подключённое устройство повторно выкладывает свою копию.
- Одновременные изменения сохраняются обеими версиями и требуют выбора пользователя. Неполученные данные не считаются подтверждёнными.
- Данные, ключи и резервные копии не перезаписываются синхронизацией единого SQLite-файла.
- История и подтверждения остаются в облаке и тоже занимают место. Облачная передача не заменяет независимую резервную копию.

Синхронизатор испытан моделированием нескольких устройств, обрывов и повреждения данных. Подключение к реальному аккаунту Яндекс Диска и готовая нативная Mac-сборка пока не выполнены.

## Пароли

Отдельное шифрование AES-256-GCM с PBKDF2-SHA256, 600 000 итераций и случайной солью. Минимум восемь символов. Совместим перенос прежнего WebCrypto-хранилища. Секреты не входят в кандидаты Gemini. Разблокировка действует две минуты с продлением при действиях и сбрасывается при сворачивании. Android блокирует скриншоты экрана паролей и помечает буфер обмена как чувствительный. Очистка скопированного значения через 45 секунд выполняется, если процесс продолжает работать и содержимое буфера не изменено пользователем.

## Сборка и проверки

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

Проверено на Flutter 3.47.9, Dart 3.13.7, полном JDK 21, SDK 36 и NDK 28.2. Для release нужен `android/key.properties`, указывающий на закрытый keystore. Эти файлы исключены из Git. Ключ подписи владельца хранится отдельно в `data/android-signing/`: без него обновление поверх установленной версии невозможно.

В `android/compile-sdk.gradle` зафиксирован обход ошибки `receive_sharing_intent 1.9.0`: модуль запрашивает несуществующий hash `android-37`, тогда как SDK распространяется как `android-37.0`. Используемые модулем операции совместимы с API 36. Источник ошибки: https://github.com/flutter/flutter/issues/192478.

`tool/verify_transfer.dart` проверяет зашифрованный перенос и целостность оригиналов. Опциональный `tool/live_vision_check_test.dart` проверяет настоящее зрение на искусственном изображении; по умолчанию не входит в тесты и не получает ключ из исходников.

Платформа macOS создана для общего кода, но для её сборки на этом Mac необходимо установить полный Xcode. Нынешний Python-бот продолжает работать отдельно.


## Android 0.2: коллекции и управление архивом

Чёрно-белая тема, до четырёх закреплённых папок и компактные плитки остальных. Символы папок имеют общий размер 24 × 24; запасной `<3>` рисуется меньшим шрифтом внутри той же области, чтобы выглядеть соразмерно значкам. Галерея и проводник выбираются после нажатия «+».

Внутри папки переключаются список и сетка по два квадратных превью в ряду. Фото, первая страница PDF, кадр видео и доступные встроенные обложки показываются локально; для остальных материалов используется прочитанный текст или значок формата. Зашифрованный кеш превью исключает повторную обработку при каждом открытии. Медиа без доступной обложки получает обычную карточку.

Сообщения чата подстраиваются под содержимое. У фото нет дублирующего имени и блока размера, время находится на самом изображении. Обычный свайп сообщения влево открывает подтверждение удаления без удержания. Обычное удержание сохраняет меню действий.

В меню папки доступны правило, закрепление, выбор нескольких файлов и удаление папки с содержимым. Обычное удаление отправляет материалы в корзину. «Очистить абсолютно всё» в настройках безвозвратно удаляет все данные, историю, корзину, пароли, настройки и ключи на текущем устройстве, создаёт новый архив и отключает старую синхронизацию. Существующие копии на Mac и других устройствах не стираются.

Правило папки задаётся обычным языком, например «Все материалы, связанные с ресторанами». Более новое подходящее правило имеет приоритет перед предыдущими, включая правила расширений. Для старых материалов пересмотр запускается только галочкой «Проанализировать другие папки на нужные файлы». Обрабатываются небольшие пакеты уже прочитанных описаний; фото без описания может потребовать отдельного визуального разбора. Без галочки готовые записи не пересматриваются. Форматные правила (например `mp3, flac`) применяются без модели.

Видео без пояснения сразу попадает в «Видео» без расходов Gemini. Сам файл видео никогда не отправляется в модель; если владелец добавил пояснение, для выбора темы может обрабатываться только этот короткий текст. Локальный кадр-превью также не требует Gemini.


## Фирменный знак в 0.2.1

Основой бренда выбрана наклонённая спиральная галактика. Утверждённый мастер хранится в `assets/brand/galaxy-master.png` в корне репозитория; `scripts/apply_brand.py` создаёт производные размеры для интерфейса, Android launcher, Android 13 themed icon, заставки, favicon, Telegram и macOS. В интерфейсе используется `assets/logo.png` из приложения. Обновление подписано прежним ключом и устанавливается поверх 0.2.0 с сохранением данных.


## Прокрутка и жесты в 0.2.2

Удаление вызывается горизонтальным свайпом влево; вертикальные движения остаются прокруткой. Обычное удержание открывает прежнее меню действий. Подтверждение «Да, удалить / Нет» сохраняется.

Высота фото резервируется до загрузки превью. Для новых фото пропорции сохраняются в записи, для старых — вычисляются из заголовка изображения или кеша превью и сохраняются в зашифрованном индексе. Подгрузка картинки не меняет размер уже показанного сообщения. Стабильные ключи сообщений сохраняют их состояние при обновлении анализа; полоска обработки также не меняет высоту области чата.


## Навигация в 0.2.3

Нижняя панель вкладок удалена. В чате снизу находятся только прикрепление, поле «Сохранить мысль…» и отправка. Нажатие на галактику или «Изbrainое» открывает компактную вертикальную панель четырёх иконок: чат, поиск, подборки и пароли. Текущий раздел выделяется, нажатие снаружи закрывает панель. Появление и скрытие анимированы; системная настройка уменьшения анимации учитывается. Иконки имеют подписи для экранного диктора и всплывающие подсказки при удержании. Поиск из меню открывается внутри основного экрана, поэтому переключение через логотип доступно во всех четырёх разделах.
