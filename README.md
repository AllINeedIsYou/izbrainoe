# Изbrainое — личная внешняя память в Telegram

**Пересылай важное в один чат. Возвращайся к нему через понятные подборки и поиск своим языком.**

Изbrainое решает проблему «Избранного», которое постепенно превращается в бесконечную ленту: документы, заметки, ссылки и голосовые сохранены, но владелец забывает об их существовании. Здесь привычка отправлять всё в один чат сохраняется, а извлечение текста, организация и поиск берёт на себя программа.

Проект рассчитан на владельца и нескольких приглашённых тестировщиков. Текущая версия работает на Mac, по умолчанию использует бесплатные локальные модели, поддерживает Gemini 3.8 Flash и открывается в Telegram Mini App. Бот: [@izbrainoe_bot](https://t.me/izbrainoe_bot). Доступ закрытый, одного перехода по публичной ссылке недостаточно.

## Концепт продукта

### Вход должен быть проще организации

Человек не обязан заранее придумывать папку, теги и название. Он пересылает сообщение, документ, фотографию, ссылку или голосовое. Программа сохраняет оригинал, получает доступный текст, определяет назначение и предлагает подборки. Один материал может относиться к нескольким подборкам без копирования файла.

Пример: при поступлении в вуз человек отправляет договор, памятку и расписание. Они должны находиться вместе по назначению, а внутри могут иметь более конкретные категории. Слово «университет» само по себе не делает любой материал договором: важны текст, тип документа и пояснение человека.

**Назначение важнее случайной темы текста.** Сочинение о дружбе в школьном контексте должно попадать в «Русский язык / Сочинения», а не автоматически превращаться в папку «Психология». Темы и ключевые слова полезны для поиска, но не должны подменять тип материала.

### Личное уточнение меняет понимание архива

Пользователь добавляет к одному материалу пояснение: «Это сочинение по русскому языку». Программа:

1. Заново анализирует этот материал с учётом пояснения.
2. Запоминает исправленный пример отдельно для этого пользователя.
3. Ищет связанные записи по типу, предмету и близости текста.
4. Повторно анализирует найденные записи с подходящими личными примерами.
5. Обновляет автоматические подборки и сообщает, сколько материалов проверено и изменено.

Например, другое сочинение без слова «сочинение» в названии может получить ту же подборку по структуре текста и личному примеру. Математические задачи при этом не должны перемещаться вместе с ним. Ручной выбор папок остаётся закреплённым. При совпадении типа и предмета программа может перенять явно выбранное название подборки для других похожих записей.

Это **память исправленных примеров**, а не обучение весов нейросети. Чем больше качественных пояснений, тем больше полезных ориентиров; автоматического улучшения от самого количества сообщений никто не гарантирует. Противоречащие друг другу примеры могут оставлять неопределённость. Текущая версия не строит полноценную модель личности и не понимает любую ситуацию безошибочно.

### Неясное хранится честно

Если фотографии или файлу не хватает контекста, материал остаётся в «Неразобранном» или получает только категорию, для которой есть основания. Пользователь может добавить пояснение позднее. Для старой записи без оригинала интерфейс прямо пишет, что содержимое не прочитано, и предлагает прикрепить файл.

«Неразобранное» — очередь уточнения, а не результат для большинства понятных документов. При этом уменьшать её за счёт выдуманных папок нельзя. В карточке показываются краткое описание, распознанный тип и предмет, фрагменты-основания и статус чтения.

### Два пути возвращения к информации

- **Поиск в чате:** «Найди…», кнопка «🔎 Найти» и короткий голосовой запрос после этой кнопки. Работают русские словоформы и поиск по описанию через векторную модель. Числа являются обязательным условием: задание 19 не подменяется заданием 18.
- **Подборки в Mini App:** просмотр разделов и материалов, уточнение контекста, исправление папок, чтение извлечённого текста, скачивание и получение оригинала в Telegram.

Поиск возвращает реальные сохранённые записи. Генеративный чат с ответами обо всём содержимом архива пока не реализован.

## Как пользоваться

1. Откройте бота по личной ссылке подключения и нажмите «Старт».
2. Перешлите материал. В ответе появится подборка и, для вложения, статус чтения.
3. Для уточнения ответьте на исходное сообщение или нажмите **«Добавить контекст»**. В Mini App откройте карточку → **«Изменить»** → пояснение.
4. Поясняйте назначение: «Конспект по физике для первого курса», «Сочинение по русскому», «Договор на общежитие». Уточнение запускает пересмотр связанных материалов.
5. Для удаления отправьте **ровно `удалить`** в пояснении или ответом на конкретную сохранённую запись. Допустимы регистр, пробелы и точка/восклицательный знак. Фраза «не удалять» или «можно удалить позже» удалением не считается. Это перенос в корзину; восстановление — **Настройки → Корзина**. Сообщение в самом Telegram не удаляется.
6. Для повторного чтения одного файла: **«Прочитать заново»** в карточке. Для всего архива: **Настройки → Переразобрать материалы**. Разбор работает в фоне, прогресс виден сверху.
7. Если оригинал не скачан, выберите **«Добавить оригинал»** в карточке. Текст будет извлечён, а существующие пояснение и ручные папки сохранятся.

`/help` описывает эти возможности. `/cancel` отменяет режим поиска или добавления контекста.

**`/clear`** удаляет учтённые ответы бота и твои служебные сообщения в Telegram: `/start` (включая ссылку подключения), `/help`, `/cancel`, `/clear`, нажатия «Подборки» и «Найти». Поддерживаются варианты кнопки 🗂, 📁 и 📂. Сама команда `/clear` тоже исчезает, уведомление о результате — через 8 секунд. Фото, файлы, обычные заметки, пояснения к материалам, поисковые запросы и записи в архиве сохраняются. Пересланная команда или подпись к фото считается материалом, а не служебным сообщением. Учёт служебных сообщений сохраняется при перезапуске. Telegram разрешает боту удалять сообщения в личном чате только в течение 48 часов. У бота нет доступа к старой истории: для старой неучтённой команды, нажатия кнопки или ответа бота ответьте **на него** командой `/clear`. Сообщение другого человека или другого бота, обычная заметка и фото таким способом не удаляются. Неудачные удаления остаются в учёте для повторной попытки; результат показывает обработанные, просроченные и недоступные сообщения. Команда не очищает архив и корзину.

## PDF: что читается и почему

По умолчанию берутся **первые четыре страницы**, настройка `PDF_PREVIEW_PAGES` допускает 2–4. Это компромисс между качеством определения назначения, скоростью и расходом памяти. Полный файл не режется: ограничение относится к тексту для анализа.

Порядок обработки каждой выбранной страницы:

1. PDFKit пытается получить текстовый слой.
2. Если букв слишком мало, страница превращается в изображение и проходит OCR Apple Vision.
3. В карточке сохраняется понятный статус: например, «Прочитаны первые 4 из 12 страниц PDF; OCR: 2 стр.».
4. Если нативный компонент недоступен, используется pypdf для текстового слоя. Для сканов в этом случае нужен установленный OCR.

Зашифрованный PDF не обходится. Если первые страницы — пустые обложки, качество скана низкое или нужная тема начинается дальше, понадобится пояснение. Чтение четырёх страниц не гарантирует понимания всего документа.

У облачного [Telegram Bot API](https://core.telegram.org/bots/api#getfile) есть ограничение скачивания файлов до 20 МБ. Более крупный файл может существовать в Telegram и возвращаться по его идентификатору, но серверу недоступно его содержимое. Решение в этой версии — **прикрепить оригинал до 100 МБ через Mini App**. Подключение платной модели само по себе этот предел Telegram не исправит.

Старые записи, созданные только из наблюдаемого названия вложения, не являются прочитанными PDF. В интерфейсе они помечены; для анализа нужен сам файл. В репозитории реальных личных материалов нет.

## Как сбалансированы качество, скорость и расход

Gemini получает само изображение целиком: структура таблицы, связи на схеме, оси графика, заголовки и расположение блоков участвуют в разборе вместе с OCR. Первый проход использует изображение с длинной стороной до 1536 пикселей; JPEG сохраняет чёткость печатного текста. PDF ограничен первыми 2–4 страницами. Ответ включает назначение, тип, краткую визуальную характеристику и отличительные признаки. Типы и темы открыты: архив не ограничен школьными предметами.

Уверенный непротиворечивый вывод заканчивает обработку за один запрос. Низкая уверенность, значимая альтернатива, неизвестный публичный термин или конфликт со структурой запускают дополнительную проверку. Для мелкого текста в достаточно крупном оригинале повторный проход получает до 2048 пикселей. Пустое изображение или неизвестная личная принадлежность запрашивают пояснение без бесполезного повторения. На один разбор допускается максимум два модельных запроса. У облачного этапа ограничено время ожидания; при сбое сохранённый материал остаётся доступен, а очередь фотографий не запускает долгий последовательный разбор второй локальной моделью.

Provod обрабатывает до трёх независимых запросов одновременно через повторно используемые соединения. Telegram разбирает независимые вложения в пачке до трёх одновременно; перед командами, ответами и переключением режима очередь завершается, сохраняя порядок взаимодействий. Короткий ответ ограничен 1200 токенами, дополнительная проверка — 1600; обычный режим рассуждений низкий, проверочный — средний. Ограничение не означает, что каждый ответ расходует весь объём.

Одинаковый файл с тем же контекстом использует сохранённый уверенный результат без нового запроса. Кеш разделён по пользователям, учитывает модель, версию правил, пояснение, ручные папки и личные примеры. Пояснения и предпочтения обновляют ключ кеша. «Прочитать заново» выполняет свежий разбор. Кеш хранится в приватной базе до семи дней. Ручные папки сохраняются.

## Что означает доступ к интернету

Поиск запускается после первого вывода, когда справка может устранить конкретное сомнение. Модель предлагает общие понятия или термины; программа фильтрует запрос от явных личных идентификаторов, адресов, ссылок и секретов. Используются поиск и выдержки Википедии, при недоступности — Bing RSS и DDGS. Это программный поиск общих понятий, а не Google Lens и не неограниченный браузерный агент.

Программа читает до двух справочных страниц или доступных выдержек, затем передаёт источники на дополнительную проверку вместе с исходным материалом. Ссылки, загруженный текст и результат поиска сохраняются в карточке. Страницы и документы считаются недоверенными данными: их команды не выполняются. Запрос ограничен по времени, скачиваемому объёму и числу страниц; переходы по найденным ссылкам и адресам проходят проверку. Справка кешируется на сутки.

Веб-источники помогают сравнить признаки типов и понять термин. Они не доказывают подлинность личного файла и не восстанавливают нечитаемый оригинал. Если поиск недоступен, не дал релевантных результатов или сомнение осталось, карточка показывает это и предлагает пояснение. Изображение личного файла передаётся подключённой модели; поисковику передаётся общий термин.

`WEB_LOOKUP=0` выключает справочную проверку. Основной визуальный разбор продолжает работать.

### Контрольный прогон 29.10.2026

На текущем Mac проведён прогон полного пути сохранения и анализа 10 разных искусственных изображений: расписание, объявление о поступлении, чек, список покупок, рецепт, тезисы сочинения, учебная карточка по физике, график, электрическая схема и пустой лист. Получено 10 запросов за 28,05 секунды, 16 103 входных и 2 510 выходных токенов; оценка стоимости 1,7428 ₽. Назначения на этом контрольном наборе определены верно; пустой лист запросил контекст. Повторный файл обработан из кеша за 0,086 секунды без нового модельного запроса.

Прогон включает OCR, локальный поиск и реальные ответы Provod; доставка файлов из Telegram заменена чтением подготовленных файлов, поэтому сетевое скачивание Telegram в 28,05 секунды не включено. Это измерение конкретного набора и нагрузки, а не SLA или оценка ошибки на всех реальных фотографиях. Живая справочная проверка кассового ордера получила и прочитала две статьи примерно за 5,25 секунды.

## Локальная версия и стоимость

Текущий набор: **Qwen3 4B** для анализа, **Qwen3 Embedding 0.6B** для поиска, **whisper.cpp base** для речи, **Apple Vision** для OCR. По умолчанию обработка локальная. Gemini подключается отдельно через локальные настройки; собственный сервер и хранение при этом остаются на Mac. Модели и вспомогательные программы для локального режима скачиваются один раз.

На Mac Apple Silicon с 16 ГБ эта схема работоспособна, что проверено на настоящих запросах и сценарии переноса пояснения между сочинениями. Задержка зависит от размера документа, прогрева модели, нагрузки и очереди; мгновенной обработки всех файлов сразу нет. При большом архиве пересборка может занимать минуты.

«Бесплатно» означает отсутствие подписки на модели и аренды сервера в текущей установке. Mac, электричество, интернет и место на диске всё равно нужны. **Бот работает, пока Mac включён, не спит и программа запущена.** Бесплатный временный туннель не даёт гарантии доступности. Массовый круглосуточный сервис для всех пользователей не обеспечивается этой схемой бесплатно.

Gemini 3.8 Flash подключена в коде отдельным адаптером, с передачей изображений, проверкой результата и учётом токенов. Без ключа и явного включения в настройках запросы к ней не отправляются. `OLLAMA_URL` остаётся ограничен локальным компьютером: это адрес другой подсистемы. Более сильная модель может улучшить сложные случаи, но не устраняет недоступность оригинала и отсутствие контекста.

## Gemini через Provod

В локальных **Настройках → Gemini через Provod** можно сохранить обычный API-ключ из кабинета Provod и задать общий месячный лимит программы в рублях. Адрес API фиксирован: `https://api.provod.ai/v1`, модель — `gemini-3.8-flash`. Проверка подключения запрашивает каталог без генерации и требует доступную модель с поддержкой изображений, JSON и ограничения ответа. Управляющий ключ не нужен.

Ключ хранится в приватном `data/ai-settings.json` с правами 600, скрыт в интерфейсе, ответах API, экспорте и Git. Ключ Google сохраняется отдельно. Выбор Provod переключает последующие разборы; старый архив автоматически не пересылается. Пароли исключены из анализа. Для PDF используются изображения первых 2–4 страниц; для фото передаётся само изображение, подготовленное на Mac.

Учёт Provod ведётся отдельно от долларового учёта Google. Для оценки используются округлённые тарифы, проверенные 29.10.2026: 61 ₽ за миллион входных и 303 ₽ за миллион выходных токенов. Перед запросом резервируется консервативная оценка текста, изображений и ответа; после — учитывается статистика `usage`. Токены рассуждений в `completion_tokens` повторно не прибавляются. При тайм-ауте, неизвестном результате или ошибке сервера резерв сохраняется; автоматического повторного платного запроса нет.

Это оценка и ограничение программы, а не банковский лимит: тарифы, кеш, скрытые рассуждения и фактические списания проверяются в кабинете Provod. Дополнительные лимиты можно задать на стороне провайдера. При ошибке сохраняется локальный разбор. Маршрут проверен с реальным ключом на трёх искусственных материалах: текстовое сочинение, фото таблицы занятий без слова «расписание» и скан PDF. Фото определено как расписание, сочинения — как русский язык; для шестистраничного PDF переданы только первые четыре изображения. Эта проверка подтверждает подключение и эти сценарии, но не гарантирует правильную сортировку любого архива.

## Подключить Gemini 3.8 Flash

1. Создайте ключ в [Google AI Studio](https://aistudio.google.com/api-keys): **Create API key** → выберите/создайте проект. Ключ не присылайте в Telegram или чат разработки.
2. Для личного архива рекомендуем обычный **платный Standard**. На бесплатном тарифе Google может использовать материалы для улучшения продуктов; тариф включается в проекте Google, программа его не меняет и не определяет.
3. Откройте приложение **на Mac** → **Настройки → Gemini 3.8 Flash**. Вставьте ключ и выберите месячный лимит программы, например $5. Нажмите **«Сохранить и подключить»**.
4. Приложение проверит доступ к модели без запуска генерации и сохранит ключ в `data/ai-settings.json` с правами 600. В интерфейс ключ повторно не возвращается, экспорт и Git его не содержат. Файл входит в приватную резервную копию `data/`.
5. Отправьте новую фотографию или откройте одну карточку → **«Прочитать заново»**. Старый архив при подключении не отправляется автоматически. Массовый пересмотр запускается отдельно и расходует запросы.

Gemini видит саму фотографию и изображения первых 2–4 страниц PDF, подготовленные на Mac. Полный PDF, встроенные вложения и его скрытые метаданные в запрос не включаются. Распознанный текст и подходящие личные примеры передаются как вспомогательные данные. Парольное хранилище не передаётся. Без достаточного основания материал может остаться неразобранным.

В настройках видны оценка расходов, резерв и число запросов за месяц UTC. Перед генерацией `countTokens` считает вход, затем программа атомарно резервирует стоимость входа и максимально разрешённого ответа. По завершении учитываются токены ответа и рассуждений. При неопределённом результате из-за обрыва резерв сохраняется: запрос мог быть оплачен. Сумма общая для владельца и тестировщиков.

**Это ограничение программы, а не гарантия банковского списания Google.** Оценка использует опубликованные тарифы, без скидок кеша, налогов и конвертации; фактический счёт смотрите в Google AI Studio. При исчерпании лимита или ошибке API сохраняется локальная обработка, причина видна в карточке. Кнопка «Переключить на локальную модель» выключает отправку новых запросов Gemini.

Пока настоящий ключ не добавлен, проверены формат запросов, обработка изображений и поведение на подменённом API. Успешное подключение и качество ответов Google подтверждаются только после проверки с настоящим ключом.

## Первый запуск на новом Mac

Поддерживаемая автоматическая установка: **macOS Apple Silicon, Python 3.12+, Apple Command Line Tools**, желательно 16 ГБ оперативной памяти и несколько гигабайт свободного места. На Windows/Linux сервер и текстовый поиск можно адаптировать, но текущая установка Apple Vision и ярлыки рассчитаны на macOS.

```bash
git clone https://github.com/AllINeedIsYou/izbrainoe.git
cd izbrainoe
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -r requirements-runtime.txt
.venv/bin/python scripts/setup_local.py
```

Если компиляторы Apple отсутствуют, сначала выполните `xcode-select --install` и дождитесь установки. Вместо последних шагов можно открыть **«Установить компоненты.command»**. Скрипт скачивает программы из официальных проектов, собирает локальное распознавание и whisper.cpp, устанавливает модели. Токен он не читает и существующие настройки не заменяет.

Затем:

1. В созданном **`Настройки.env`** укажите токен BotFather в строке `BOT_TOKEN=`. Токен не публикуйте и не вставляйте в README.
2. Откройте **«Запустить Изbrainое.command»** или выполните `.venv/bin/python run.py`.
3. В локальном интерфейсе: **Настройки → Подключить тебя как владельца**. Откройте личную ссылку и нажмите «Старт» в Telegram.
4. Для тестировщика создайте отдельное приглашение в настройках. Ссылка владельца для этого не подходит.
5. Не закрывайте окно запуска. Остановка — Ctrl+C в окне запуска; для фонового запуска есть «Остановить Изbrainое.command». Повторный запуск не создаёт второго экземпляра. Изменили настройки — перезапустите программу.

Проверка установленных компонентов: `.venv/bin/python scripts/setup_local.py --check`.

Настройки читаются из `Настройки.env`, затем `.env`; уже заданные переменные окружения имеют приоритет. Файлы с секретами исключены из Git.

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен своего Telegram-бота |
| `BOT_USERNAME` | Имя бота без `@` |
| `PUBLIC_URL` | Собственный HTTPS-адрес; пусто — попробовать временный туннель |
| `ENABLE_TUNNEL` | `1` — Cloudflare Quick Tunnel при наличии токена, `0` — отключить |
| `PORT` | Локальный порт приложения, по умолчанию 8765 |
| `OLLAMA_URL` | Локальный Ollama, обычно `http://127.0.0.1:11435` |
| `EMBED_MODEL` | `qwen3-embedding:0.6b`; пустое значение отключает векторный поиск |
| `CHAT_MODEL` | `qwen3:4b`; пустое значение оставляет правила и личные примеры |
| `PDF_PREVIEW_PAGES` | От 2 до 4, по умолчанию 4 |
| `MAX_UPLOAD_MB` | Прямая загрузка через Mini App, от 20 до 100 МБ |
| `WEB_LOOKUP` | `1` — общая интернет-справка, `0` — отключена |
| `WEB_BACKEND` | Резервный поисковый backend DDGS, по умолчанию `bing` |
| `ALLOWED_USER_IDS` | Дополнительные разрешённые Telegram ID через запятую |
| `DATA_DIR` | При необходимости другой путь к базе и оригиналам |

### Телефон и временный адрес

При запуске с токеном программа может создать [Cloudflare Quick Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/). Для текущей сети используется HTTP/2. Кнопка подборок обновляется отдельно для подключённых пользователей. После перезапуска адрес меняется: закройте старое Mini App и откройте подборки кнопкой меню снова.

Без туннеля и собственного HTTPS интерфейс доступен локально на Mac, а сохранение и поиск в чате работают через Bot API. Существующий webhook автоматически не отключается, чтобы не ломать другую работающую установку.

## Данные и пароли

Обычные материалы хранятся в `data/izbrainoe.sqlite3`, оригиналы — в `data/files/`. Они проходят через Telegram, а при использовании Mini App с туннелем — ещё и Cloudflare. **Обычный чат бота не имеет сквозного шифрования.** Локальная обработка моделями не делает всю доставку сквозным шифрованием.

Пароли вводятся в отдельном разделе Mini App. Все поля записи шифруются на устройстве через **AES-256-GCM**, ключ получается из главного пароля через **PBKDF2-SHA256, 600 000 итераций**, со случайной солью. При сохранении генерируется новый IV. Сервер получает зашифрованный блок, который не попадает в общий поиск и модели.

Хранилище блокируется при уходе с экрана, сворачивании и после двух минут бездействия. Главный пароль и ключ не записываются в localStorage. Восстановления главного пароля нет. Копирование секрета помещает его в системный буфер; автоматической очистки буфера пока нет. Это тестовая реализация без независимого аудита, проверять её следует на вымышленных секретах.

Распознавание некоторых признаков секретов в обычном сообщении предотвращает их сохранение в общем индексе, но не распознаёт все возможные пароли и не отменяет передачу исходного сообщения в Telegram.

### Резервное копирование

Экспорт JSON содержит тексты, метаданные и зашифрованное хранилище, **не бинарные оригиналы**. Для полной резервной копии остановите программу и сохраните папку `data/` в приватном месте. Главный пароль к разделу паролей всё равно нужен. Корзина автоматически не очищается.

В Git не входят настройки с токеном, база, оригиналы, личные тестовые записи, журналы, виртуальная среда, модели и нативные бинарники. Репозиторий содержит воспроизводимые исходники и скрипт подготовки компонентов, а не копию личного хранилища.

## Что остаётся улучшить

- Оценка качества на большем наборе материалов: правильные папки, ошибочные переносы, время обработки, доля действительно неясных записей.
- Управление самой памятью: просмотр и отключение ошибочных примеров, объяснение связи между двумя материалами, история изменений и отмена массового переноса.
- Более гибкая иерархия подборок, синонимы названий, объединение похожих разделов по решению человека. Сейчас `Русский язык / Сочинения` — название подборки с визуальной иерархией, не полноценное дерево папок.
- Надёжная долговременная очередь заданий: сейчас задачи фоновые в памяти процесса. При остановке пересмотр прерывается; его можно запустить заново.
- Работа со ссылками: содержимое сохранённых сайтов автоматически не скачивается. Видны адрес, подпись и текст сообщения.
- Большие файлы через собственный Local Bot API Server, дополнительный OCR для других ОС, более длинные голосовые.
- Постоянный адрес, автономный сервер и мониторинг для круглосуточной работы; это отдельный этап размещения.
- Сравнительная оценка качества Gemini и локального режима на реальных материалах после подключения ключа; при необходимости другие облачные провайдеры.

Ни одна модель не даёт «идеальную» сортировку. Критерий продукта — заметно меньше потерянных материалов и ручной работы при понятных основаниях, возможности исправления и сохранности оригиналов.
